# Gestion d'Inventaire - Backend

Production-ready backend for an Industrial Inventory Management System for OCP Phosboucraa.

This repository will contain a modular Django 5 project using Django REST Framework, PostgreSQL (Neon), JWT authentication, Cloudflare R2 for file storage, Resend for emails, Celery for background tasks, and a full CI/CD pipeline.

See docs/ for full documentation.
